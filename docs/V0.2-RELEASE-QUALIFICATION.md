# v0.2 structured-concurrency release qualification

Date: 2026-10-23. Status: **RELEASE QUALIFICATION PASSED**.
Target: Issue [#23](https://github.com/alex-1974/concurrency-d/issues/23).

The maintainer accepted the M1 API and ADRs. Feature PR #42 passed x86_64
DMD/LDC and native ARM64 CI and merged to `develop` at `14e3a7b`. The versioned
candidate PR #43 and subsequent `develop` merge passed all compiler and native
ARM64 CI. Both DMD and LDC independently built and ran the exported 0.2.0
archive consumer. The tested versioned tree is promoted from `develop` to
`main` for the release.

## Feature-commit CI and local receipt

The signed feature commit `a2ebc033a5214bf9351c1135e8c55a9cebc55559`
passed [GitHub Actions run 39834357860](https://github.com/alex-1974/concurrency-d/actions/runs/39834357860):
DMD 2.111, LDC 1.41 and native ARM64/LDC 1.41. The commit's tree is
`7fa88308eb5fcab3a99051338517317d15c29118`; its exported archive has
20 allowed files and passed both external compiler consumers. The following
local checks supplied additional evidence before that commit:

- `dub test --compiler=dmd --force`: PASS, five modules.
- `dub test --compiler=ldc2 --force`: PASS, five modules.
- `tools/validation/m0_public_api.py`: PASS with DMD 2.111 and LDC 1.42,
  including debug/release, LDC `-O3`, scope/fork-join/cancellation/GC consumers,
  DIP1000 positive/limitation probes, moved-scope-view lifetime enforcement,
  and all compile-negative fixtures.
- `tools/validation/m0_lifecycle.py`: PASS with DMD 2.111 and LDC 1.42,
  including every normal and injected fail-stop branch; LDC includes `-O3`.
- Public Ddoc generation: PASS with DMD 2.111 and LDC 1.42.
- Internal unit binary repeated 100 times: PASS.
- External public consumer repeated 30 additional times after the scope-state
  move fix: PASS.
- Conditional parking smoke: PASS for 1/2/4 workers, three repetitions and 256
  isolated wakes per repetition. All 2,304 tasks completed; idle CPU was below
  0.0005 cores in each 300 ms window. See ADR-0003 for latency and thermal scope.
- Public owned-storage diagnostic: PASS with LDC 1.42 release, 2,048 tasks,
  two workers and five rotated rounds. Tiny, 512-byte inline-context and
  transitive GC-graph arms all preserved their checksums while the blocked-worker
  retention arm dropped every measured handle before collection. The XPS sample
  ran from 53°C to 71°C at roughly 2,400 RPM; GC byte deltas remain observational.
- A temporary Git tree built through an alternate index from the intended
  candidate files passed the exported archive consumer with DMD and LDC.
  The archive contained exactly 20 allowed
  files and both external consumers passed. This checks package shape and
  consumption without staging or committing the working tree; its manifest
  still identifies version 0.1.0.
- `git diff --check`: PASS.

The local commands exercised the working tree directly. The feature commit
